# Ralwix Press-Kit

Welcome to the official **Ralwix Press-Kit** repository. This repository contains all approved visual assets, brand guidelines, and information for media, partners, and journalists.

## 📦 What's Inside

*   **`logos/`** – Official brand logos and logomarks in multiple formats.
*   **`banners/`** – Official marketing banners, social media headers, and promo graphics.
*   **`screenshots/`** – Official in-game screenshots and high-quality gameplay previews.
*   **`clothing/`** – Official templates and assets for merchandise and clothing designs.
